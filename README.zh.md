# SneakRead · 摸鱼

**界面资源全部内嵌的单 HTML 阅读器；联网直接读取目标网站，并在本机解析正文、伪装显示。**

[English](README.md) · [MIT 许可证](LICENSE) · 无后端、无账号、无统计

## 使用

1. 双击构建生成的 `sneakread.html`。启动界面不需要服务器或网络连接。
2. 在「网页地址」输入网址，直接联网读取允许跨域的网站；若要读取非 CORS 网站，按 [browser-extension/README.zh.md](browser-extension/README.zh.md) 安装 Chromium 扩展，再从扩展图标打开阅读器。扩展会在后台等待目标网站渲染后提取 DOM。
3. 选择伪装阅读；文件菜单和命令面板用于切换外观、语言等设置。
4. 按 `Esc` 显示预算表，再按一次回到阅读；可开启失焦自动隐藏。
5. Excel 外观中，左右拖动表格与正文之间的分隔条调整宽度；也可用 Tab 聚焦分隔条后按左右方向键调整，Home / End 到达边界。窗口宽度不超过 820px 时自动使用正文单栏。宽度不写入本地记录，刷新或切换外观后恢复默认比例。

**资源离线不等于禁止联网阅读。** 所有应用脚本、样式、字体和图标内嵌；独立版网址读取只连接目标网站及其重定向，不使用第三方正文抓取服务。扩展版会在当前浏览器配置中打开目标页，等待脚本渲染后在本机提取 DOM，可使用已有登录状态。验证码、付费墙、反爬和需要持续交互的内容不保证可读。点击正文链接会在当前阅读器中加载目标页，保留所选外观；图片默认显示加载按钮，仅点击后在正文中显示，失败时可点击重试。VS Code 默认进入预览页，源码页保留 Markdown 原文。同一文章的章节链接直接在正文中滚动。

## 隐私与会话数据

- 所有应用脚本、样式、必要图标与许可均内嵌在独立单 HTML 中，以 gzip 压缩；扩展版本将应用资源作为扩展本地文件打包，不从 CDN 加载。
- 不包含第三方阅读服务或外部统计。打开网址、点击正文链接时读取目标页；点击图片按钮后才在阅读器中请求图片原地址。扩展后台渲染目标网站时，网站自身仍会加载其脚本、图片等资源；按需图片开关仅控制阅读器正文中的展示与请求。
- 独立 HTML 的 CSP 允许 HTTP(S) 内容与图片请求，但禁止外部脚本、远程字体、框架和表单提交；扩展版本由扩展权限读取 HTTP(S)。获取的 HTML 在阅读器中不会作为脚本执行；链接和图片仅保留 HTTP(S) 地址。
- 文章仅保留在当前阅读器标签页的内存中；同一会话内可通过浏览器后退返回已打开的网页。刷新或关闭标签页后正文清除，粘贴正文和本地文章导入功能已移除。
- 浏览器本地存储只用于语言、署名和外观设置。打开此版本时会清理旧版本保存的文章。
- 取消读取或关闭阅读器会断开对应后台任务并关闭目标标签页；加载、等待渲染和提取共用一个总时限。
- 老板键只切换画面，不加密文章，也不能阻止他人检查当前页面。

## 构建与开发

需要支持 Vite 8 的 Node.js（20.19+ 或 22.12+）及 pnpm。安装依赖和读取新网址需要网络；启动界面和阅读当前会话中已打开的文章不需要网络。

```bash
pnpm install
pnpm build      # 类型检查，生成 ../sneakread.html 和 browser-extension/ 内的扩展页面
```

仅打包时可执行 `node build-single.mjs`。独立发布产物是上一级目录中的 `sneakread.html`；扩展目录同时生成 `sneakread.html`、`app.js` 和 `app.css`。源码 `index.html` 使用严格 CSP；开发时重新构建并打开对应产物，不使用 Vite HMR 或预览服务器。

运行需要支持 `DecompressionStream` 的现代 Chrome、Edge、Firefox 或 Safari，并启用 JavaScript。gzip 启动器使用浏览器原生解压和内联脚本，不使用 `eval`。第三方许可解压后保存在页面的 `#third-party-licenses` 中。

## 验证

- Chromium 检查覆盖网址读取、非法协议拒绝、老板键、仅会话内保留的网页导航、标题与代码保真，以及同页章节链接。不打开网址时无 HTTP(S) 请求。
- 本地生命周期检查覆盖加载中取消、等待渲染时取消、目标页提前完成、总时限内的慢页面，以及两个阅读器任务互不干扰；这些检查使用模拟 Chrome API 和虚拟时钟。
- 此前已在隔离 Chrome 配置中实际加载扩展，验证动态网页的相对链接、连续章节导航、失败时保留原文、按需图片及重试，以及 Excel 分栏拖动和窄屏布局。
- 现有浏览器检查继续覆盖安全相对地址、脚本协议拒绝、恶意 HTML 不执行、不自动请求资源、15 种外观和 Excel 分隔条键盘边界。新增验证脚本只保留在本地，不进入提交或交付产物。
- 尚未在 Safari、Firefox 上实际验证。
