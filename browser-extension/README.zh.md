# SneakRead 浏览器扩展

这是完整的 Chromium Manifest V3 阅读器扩展：`sneakread.html` 随扩展安装，应用资源打包在扩展目录内。输入网址后扩展在后台打开目标页，等待网站脚本渲染，再提取渲染后的 DOM；正文仍在本机解析，不使用第三方中转。

## 安装

1. 从 [GitHub Releases](https://github.com/llc2214926/sneakread-browser-extension/releases/latest) 下载扩展 ZIP 并解压。
2. 打开 Chrome 或 Edge 的扩展管理页，开启「开发者模式」。
3. 选择「加载已解压的扩展」，选中解压后包含 `manifest.json` 的文件夹。若从源码安装，也可选中本项目根目录或 `browser-extension` 目录。
4. 点击浏览器工具栏上的 SneakRead 图标打开阅读器；也可以在扩展详情页打开扩展页面。

扩展需要读取 HTTP/HTTPS 网页；目标页会在当前浏览器配置中加载，因此可使用已有登录状态。扩展不会向目标页额外注入登录凭据。只给扩展授予你信任的浏览器配置文件使用。

## 链接、图片与布局

- 点击正文链接后，在同一个扩展阅读页继续加载目标网页，保留当前外观；同一文章的章节链接直接滚动到正文目标。可使用浏览器后退返回当前标签页会话内已打开的文章。
- 正文只保留在当前页面内存中，刷新或关闭页面后清除；粘贴正文、本地文章导入和持久阅读记录已移除。语言、署名与外观设置继续保存在浏览器中。
- 图片默认显示「点击加载图片」按钮；点击后才在正文中请求和显示，失败时显示重试按钮。图片请求不发送 Referer；部分防盗链或需登录的图片可能无法加载。
- VS Code 默认打开可交互预览，切换源码页后显示 Markdown 原文。
- Excel 中可左右拖动表格与正文的分隔条，也可用 Tab 聚焦后按左右方向键调整；Home / End 移到边界。窄屏自动隐藏表格和分隔条。刷新或切换外观后宽度恢复默认比例。
- 更新扩展后请重新打开阅读页并输入网址读取。
- 目标网站后台渲染时可能自行请求图片、脚本等资源；默认不加载图片仅指阅读器正文，不会阻止原网站正常渲染。


## 边界

- 仅支持 Chrome、Edge 等 Chromium 浏览器；未提供 Firefox 版本。
- 可处理大多数公开页面和当前浏览器已登录的页面；不能绕过验证码、付费墙、反爬、网络错误，或必须点击、滚动、持续交互后才出现的内容。
- 扩展会短暂创建后台标签页等待渲染，提取 DOM 后自动关闭；取消读取、关闭阅读器或超过总时限也会关闭该后台页。目标网站可能仍能看到取消前已经发生的访问。
- `sneakread.html` 仍会作为上一级目录的独立单 HTML 产物生成；扩展目录内的副本由构建命令同步更新。
- 直接打开独立 HTML 仍受普通浏览器 CORS 限制；需要读取非 CORS 网站时使用扩展页面。
